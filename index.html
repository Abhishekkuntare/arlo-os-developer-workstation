GOOD TO KNOW

Questions, answered.

The essentials for choosing, downloading and getting started with ARLO OS.

What is ARLO OS?

ARLO OS is a customizable desktop environment with built-in apps, virtual workspaces, developer tools and Ghost AI, an optional AI assistant. Explore the screenshots and interactive preview on this page to see it in action.

Which platforms can I get ARLO OS for?

ARLO OS is currently available for Windows. macOS and Linux releases are coming soon; visit the official GitHub Releases page for updates. Windows users can install it from the Microsoft Store or use the direct x64 installer on this page.

Is ARLO OS free?

Yes. ARLO OS is free to download, and its source code is available on GitHub.

Is the Windows installer signed?

The standalone Windows installer is not Authenticode-signed, so Windows may show an Unknown publisher or SmartScreen warning. The Microsoft Store version is signed and receives updates through the Store.

Does Ghost AI require an internet connection?

Ghost AI's Gemini-powered chat needs an internet connection and a Gemini API key. Optional wake-word speech recognition runs locally on your device; microphone audio stays on-device unless you ask Ghost AI for a response.
